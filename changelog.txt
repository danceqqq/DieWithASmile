Version 2.4

Edit Position
- New bottom-left button opens Edit Position: drag the logo, the music player, and the main-menu button column
- Save (bottom-right) writes logo position, player position, menu position, and logo scale
- Toggling Edit Position again cancels without saving
- While editing, the screen dims, red guides show what you can grab, and gallery / logo / social chrome tucks away so it does not eat clicks
- Save sits above "Switch Menu Theme" and the swap is blocked on the save click, so you no longer get thrown onto the default Terraria menu

Menu buttons
- The left-side vanilla list (Singleplayer, Multiplayer, and the rest) moves on both X and Y
- The red hitbox follows the drawn text instead of sitting under the first items and covering the player
- Hover and click still work after you move the list, including after Save

Music player
- In Edit Position the collapsed pause orb can be dragged freely
- Grabbing the player no longer drags the button list
- Outside edit mode it still expands on hover, seeks, loops, shuffles, and opens the playlist / upload flow

Logo
- Five built-in logos: Classic, Gothic, Rings, Hands, Sticker
- Hands keep the floating extra layer; Sticker keeps the watermelon-smile head on the cat-head mark
- Sticker head is sized to fill that silhouette so the outline reads, without swallowing TERRARIA
- In Edit Position, hover the whole logo and scroll to resize it (about 45%–200%); a label under the box shows the percent
- Scale is saved with the layout and applies to built-in, custom, and other-mod logos

Custom uploads (PNG / JPG / JPEG)
- Background gallery and logo gallery each have an Upload card
- Files are copied to Documents/My Games/Terraria/tModLoader/DieWithASmile/logo and .../wallpaper (same root as custom music)
- Cards show a live preview of the image
- Custom picks are stored in settings.json and come back after restart / reload
- Delete from the same gallery: Delete, then Sure? (same two-click confirm as custom songs)
- Files dropped into those folders also show up the next time the gallery scans

Other mods
- Enabled mods that add a menu theme with their own logo or background style show up as extra cards in our pickers
- Calamity (and similar themes) can be chosen for background, logo, or both while this theme stays selected
- Backgrounds call that mod's PreDrawCloseBackground; logos call PreDrawLogo / PostDrawLogo so particles and other menu effects still run when the other mod supports it
- If you disable the other mod, those cards vanish and the saved choice is cleared instead of breaking the title screen

Background gallery
- Follow music, lock a scene, or shuffle
- Shuffle interval 0–15 seconds; 0 only changes when you leave a world
- Scenes: Calamitas, Don't Forget, Come Along with Me, Last meeting, Yharim Never Die, Witch of Supreme Memories, The Soul of the Universe
- Hide / show the music player from the same panel

Persistence and polish
- Selected theme, playlist, uploads, loop, shuffle, background, logo, custom art, other-mod art, volume, and layout (positions + logo scale) are remembered
- Linear filtering on logos, custom images, and full-screen wallpapers
- Menu music still has its own slider under Settings → Volume
- Compatible with Sam's Cooler Menu Screen (player still collapses to a circle until hovered)
